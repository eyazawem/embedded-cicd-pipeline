# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 1.x     | yes       |

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub private
vulnerability reporting: open the **Security** tab of the repository and choose
**Report a vulnerability**. Include the affected version and steps to reproduce.

This is a personal portfolio project maintained on a best-effort basis: reports
are acknowledged as time permits.
